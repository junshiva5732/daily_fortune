# 스토어 등록정보 — 영어 / 일본어 / 중국어(간체)

Play Console → 스토어 등록정보 → **번역 관리 → 번역 추가**에서 언어를 추가한 뒤 붙여넣기.
기본 언어는 한국어(`listing.md`). 스크린샷은 언어별로 따로 올리지 않아도 기본 언어 것이 쓰인다
(원하면 `tool/make_store_assets.py` 캡션만 바꿔 언어별 스크린샷 생성 가능).

App Store Connect 도 동일한 문구를 각 현지화 항목에 사용.

## 日本語 (ja)

**アプリ名 (30)**
```
今日の運勢 - 干支占いと名言
```

**簡単な説明 (80)**
```
生年月日を入れるだけ。毎日変わる干支の運勢、ラッキーナンバー、今日の名言をお届け。
```

**詳しい説明**
```
🌙 毎朝、自分だけの運勢をチェック

「今日の運勢」は、干支と誕生日をもとに毎日変わるあなただけの運勢を表示するアプリです。
会員登録もログインも不要。開いた瞬間に今日の運勢が現れます。

✨ 主な機能

• 運勢スコア
  0〜100点のスコアと星評価で、今日の流れがひと目でわかります。

• 5つの詳しい運勢
  総合運・恋愛運・金運・仕事・学業運・健康運をそれぞれ詳しく。

• ラッキーアイテム
  今日のラッキーナンバー、ラッキーカラー、ラッキーアイテム、ラッキー方位。

• 干支別の運勢
  生年月日から自動で計算した干支（子・丑・寅・卯・辰・巳・午・未・申・酉・戌・亥）に合わせた運勢。

• 今日の名言
  孔子、アリストテレス、アインシュタイン、トルストイなど、時代を超えて愛される言葉を毎日ひとつ。

• 朝の通知
  好きな時刻に今日の運勢スコアをお知らせ。

• 画像で共有
  今日の運勢をきれいなカード画像にして、LINE や Instagram ストーリーで共有。

🔒 プライバシーに配慮
入力した生年月日は端末内にのみ保存され、サーバーには送信されません。
軽くて速く、不要な権限は求めません。

🎨 すっきりしたデザイン
ダークモード対応の柔らかなパープルテーマ。

日本語・English・한국어・简体中文に対応。

---
※ 運勢は娯楽目的のコンテンツです。
※ このアプリには広告が含まれます。
```

## 简体中文 (zh-CN)

**应用名称 (30)**

```

**简短说明 (80)**

```

**完整说明**
```
🌙 每天早晨，查看属于你的运势

「今日运势」根据生肖和生日，每天为你生成不同的专属运势。
无需注册、无需登录，打开即看。

✨ 主要功能

• 运势指数
  0～100 分的指数和星级评价，一眼看清今天的运程。

• 五项详细运势
  总运 · 爱情运 · 财运 · 事业·学业运 · 健康运，各有专属建议。

• 幸运物品
  今日幸运数字、幸运颜色、幸运物品和幸运方位。

• 生肖运势
  根据生日自动计算你的生肖（鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪）。

• 今日名言
  孔子、亚里士多德、爱因斯坦、托尔斯泰……每天一句经典。

• 早晨提醒
  在你设定的时间推送今日运势指数。

• 图片分享
  把今日运势做成精美卡片，分享到微信、小红书、朋友圈。

🔒 注重隐私
你输入的生日仅保存在本机，不会上传到任何服务器。
轻巧快速，不索取多余权限。

🎨 简洁设计
支持深色模式的柔和紫色主题。

支持简体中文、English、한국어、日本語。

---
※ 运势内容仅供娱乐参考。
※ 本应用包含广告。
```
