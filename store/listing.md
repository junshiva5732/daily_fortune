# Google Play 스토어 등록 정보

Play Console → 앱 → **스토어 등록정보(기본)** 에 아래 내용을 그대로 붙여넣으면 됩니다.
글자 수 제한: 앱 이름 30자 · 간단한 설명 80자 · 자세한 설명 4,000자.

---

## 앱 이름 (30자)

```
오늘의 운세 - 띠별 운세와 명언
```

## 간단한 설명 (80자)

```
생년월일만 입력하면 매일 새로운 띠별 운세와 행운의 숫자, 오늘의 명언을 알려드려요.
```

## 자세한 설명 (4,000자)

```
🌙 매일 아침, 나만의 운세를 확인하세요

「오늘의 운세」는 생년월일을 한 번만 입력하면 매일 달라지는 나만의 운세를 보여주는 앱입니다.
회원가입도, 로그인도 필요 없습니다. 열자마자 바로 오늘의 운세가 나타납니다.

✨ 주요 기능

• 오늘의 운세 지수
  0~100점 운세 지수와 별점으로 오늘 하루의 흐름을 한눈에 확인하세요.

• 5가지 상세 운세
  총운 · 애정운 · 금전운 · 직장·학업운 · 건강운을 카테고리별로 자세히 알려드립니다.

• 행운의 아이템
  오늘의 행운의 숫자, 행운의 색, 행운의 아이템, 행운의 방향까지.

• 띠별 운세
  생년월일로 자동 계산된 나의 띠(쥐·소·호랑이·토끼·용·뱀·말·양·원숭이·닭·개·돼지)에 맞춘 운세.

• 오늘의 명언
  공자, 아리스토텔레스, 아인슈타인, 톨스토이 등 시대를 넘어 사랑받는 명언을 매일 하나씩.

• 운세 다시 뽑기
  오늘 운세가 마음에 들지 않나요? 짧은 광고를 보고 한 번 더 뽑아보세요.

• 공유하기
  오늘의 운세와 명언을 카카오톡, 문자, SNS로 친구에게 공유할 수 있습니다.

🔒 개인정보 걱정 없이

입력한 생년월일은 휴대폰 안에만 저장되며 어떤 서버로도 전송되지 않습니다.
가볍고 빠르며, 불필요한 권한을 요구하지 않습니다.

🎨 깔끔한 디자인

다크 모드를 지원하는 부드러운 보라색 테마로 매일 아침 기분 좋게 하루를 시작하세요.

---
※ 이 앱의 운세는 재미로 보는 콘텐츠이며, 중요한 결정은 스스로의 판단에 따라 내리시기 바랍니다.
※ 앱은 광고를 포함하고 있습니다.
```

### 데이터 보안 양식
- 데이터를 수집하거나 공유하나요? → **예** (AdMob SDK 때문에)
- 수집 데이터 유형:
  - **기기 또는 기타 ID** → 광고 ID. 목적: 광고 또는 마케팅. 필수. 공유: 예(Google AdMob).
  - **앱 활동 → 앱 상호작용** → 광고 노출/클릭. 목적: 광고 또는 마케팅, 분석. 공유: 예.
- 암호화 전송: **예**
- 삭제 요청 가능: 예 (앱 삭제로 기기 데이터 삭제 / 광고 ID 재설정)
- 생년월일은 기기 내부에만 저장되고 **전송되지 않으므로 "수집"에 해당하지 않음** (Google 정책상 기기를 떠나지 않는 데이터는 수집으로 보지 않음)
